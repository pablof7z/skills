# Answer Style Guidelines

## Answer Style Guidelines

Answers should be as terse as possible without losing meaning. Favor skimmable answers over large paragraphs — use the shortest version that conveys the message while retaining enough context for the user to understand.

Use skimmable formatting: bullets, short sentences, and compact sections. Avoid repetition, throat-clearing, and unnecessary detail. <!-- [^019f5-0420a] -->
