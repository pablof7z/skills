# Narration Grammar

Use this reference to write the verbal layer around a conceptual visual. Build
an original voice from the user's subject and audience. Borrow rhetorical
mechanisms, not signature lines, catchphrases, or claims of authorship.

## Start With Truth, Then Compress

Begin with a real observation, lived experience, credible source, or supported
mechanism. Ask:

1. What changed from the beginning to the end?
2. What caused the change?
3. Which detail makes the claim credible?
4. Which details can disappear without changing the truth?
5. Where can the audience place its own experience into the idea?

Write the most specific true version first. Then remove context until the idea
travels, stopping before it becomes generic advice or an unsupported universal.

## Choose One Rhetorical Move

### Reframe

Rename the familiar thing by its actual function or consequence.

```text
This is not delay. It is stored pressure.
```

Use when the audience sees the evidence but interprets it incorrectly.

### Parallel contrast

Hold syntax constant and change one load-bearing word.

```text
More output fills space.
Better judgment creates signal.
```

Use when a matched comparison can isolate the difference.

### Conditional reveal

Establish a condition, then land the non-obvious consequence.

```text
If every option is available, choosing becomes the work.
```

Use when the surprise depends on accepting the setup.

### Negation flip

Repeat the core language while reversing its direction.

```text
Tools do not remove decisions.
They multiply them.
```

Use when repetition makes the inversion undeniable.

### Expectation and correction

Name the default model, then replace it with the better one.

```text
Looks like inactivity.
Works like accumulation.
```

Use when the visual can show both models with the same objects.

### Progression

Use a short sequence whose steps escalate, narrow, or transform.

```text
Try.
Notice.
Choose.
Repeat.
```

Use when order is the meaning. Do not write a list of interchangeable tips.

### Paradox

Join two apparently conflicting truths whose resolution creates the insight.

```text
The narrower the frame, the wider the recognition.
```

Use only when the contradiction resolves under inspection.

### Structural echo

Return to an opening word, shape, or proposition with changed meaning.

```text
The system creates the work.
The work recreates the system.
```

Use for loops, feedback, or a closing beat that completes the opening.

## Write for a Single Frame

- Target 6 to 15 words for the turn. Use fewer when the image already carries
  the setup.
- Prefer one declarative sentence, a matched pair, or two labeled nouns.
- Let line breaks carry pace and contrast.
- End on a concrete noun or short stressed word when natural.
- Use questions rarely and only when the question itself is the point.
- Keep punctuation structural rather than emotional.
- Choose either a turn inside the frame or an extending caption outside it by
  default, not both.

## Write for a Sequence

Give each frame one verbal function:

1. **State:** name the current model.
2. **Tension:** expose the contradiction or cost.
3. **Mechanism:** name what is actually happening.
4. **Turn:** replace the old model.
5. **Consequence:** show what the audience can now see or do.

The copy must advance with the visual state. If two frames can exchange their
sentences without damage, the sequence lacks causality.

Use start and end when the transformation is obvious. Add a middle only when
the mechanism needs to be experienced rather than explained afterward.

## Write Spoken Narration

Use the visible object as the grammatical subject. Describe the change before
interpreting it:

```text
The opening narrows.
The attempts keep coming.
The last gap closes.
What looks sudden was built one layer at a time.
```

Pause at visual changes. Do not speak every label on screen. Let silence carry
inspection and reveal.

## Write a Visual Essay

- Open with the observation, not a preamble about the topic.
- Keep paragraphs to one idea and one to three sentences.
- Move from observation to mechanism to implication.
- Place visuals at argumentative turns, not regular decorative intervals.
- End on the final implication or image. Do not add a summary that repeats it.

## Preserve the Audience Insertion Point

Keep the principle broad enough to travel across relevant experiences while
giving the audience something concrete to recognize: a threshold, choice,
delay, repeated action, hidden cost, or transformation.

Do not erase the source in pursuit of universality. The strongest general idea
usually retains one precise mechanism from the original experience.

## Cut the Verbal Layer

Remove:

- preamble and throat-clearing;
- hedging that does not encode real uncertainty;
- corporate jargon and vague abstractions;
- decorative adjectives and adverbs;
- motivational cliches;
- text that narrates exactly what the image already shows;
- calls for engagement;
- a final recap after the idea has landed.

Keep uncertainty when it is part of the truth. Direct language does not justify
false certainty.
