# Story Structures

Use this reference when an idea needs more than one simultaneous relationship.
Choose the shortest structure that produces the intended change in
understanding.

## Single Frame

Use for one contrast, mechanism, or reframe that can exist in a single visual
state.

Build in this order:

1. State the semantic spine.
2. Place the two or three load-bearing objects.
3. Make the relationship visible through position, scale, direction, or absence.
4. Add only indispensable labels.
5. Write a caption that extends the implication.

Do not force process, chronology, or multiple independent claims into one frame.

## Diptych

Use two matched frames for a decisive contrast or transformation.

- Frame 1: establish the expected, visible, or current state.
- Frame 2: reveal the actual, hidden, or changed state.

Hold canvas, scale, and object vocabulary constant so the changed variable is
obvious. Avoid using a diptych when both sides need long explanations.

## Triptych

Use three frames for setup, intervention, and consequence.

- Frame 1 — **Before:** establish the system or belief.
- Frame 2 — **Pressure:** introduce the choice, force, or missing information.
- Frame 3 — **After:** show the transformed state or reframe.

Make the middle frame an event, not a restatement.

## Short Carousel

Use four to seven frames for an argument that needs paced disclosure.

1. **Hook:** present a tension the audience can recognize immediately.
2. **Model:** show the familiar explanation or starting state.
3. **Complication:** surface what the model misses.
4. **Mechanism:** make the hidden relationship visible.
5. **Reframe:** state what the audience should now understand differently.
6. **Consequence:** show what changes in action, if useful.
7. **Close:** land one durable image or line; do not summarize every frame.

Use fewer frames whenever possible. Keep one visual system across the sequence,
but change the state enough that swiping creates discovery.

### Carousel pacing rules

- Open with meaning, not a title page.
- Alternate density: orient, compress, pause, reveal.
- Carry one object across frames when continuity matters.
- Use repetition to create expectation, then break it deliberately.
- End each frame with enough incompleteness to invite the next, except the last.
- Avoid placing the full argument in captions beneath every frame.

### Platform-native reveal

- Use the seam between two frames as a cut, contrast, or missing boundary.
- Let a swipe reveal the answer only after the first frame establishes the
  question or incomplete state.
- Keep the carried object in the same position when the audience must compare
  states; move it only when movement carries meaning.
- Recompose for each platform's crop and reading distance instead of resizing a
  master blindly.

## Motion Storyboard

Use motion when movement itself explains direction, causality, accumulation, or
transformation.

Specify each beat with:

```text
Beat:
Visible state:
Semantic change:
Motion:
Copy:
Hold or transition:
```

Prefer one meaningful transition over continuous activity. Use easing and speed
to match the concept: accumulation can accelerate, resistance can hesitate,
revelation can snap into place. Keep the final frame stable and independently
legible.

## Presentation Sequence

Use a presentation sequence when the speaker controls pace and can add verbal
context.

- Put one relationship on each slide.
- Let spoken narration provide evidence and nuance outside the frame.
- Reuse spatial positions across slides so the audience tracks change.
- Reveal complexity progressively rather than shrinking a complete system map.
- Return to the opening visual near the end with one meaningful change.

## Long-Form Visual Essay

Use visuals as structural turns inside prose, not as decoration between
paragraphs.

For each visual, assign one function:

- establish the model;
- compress evidence;
- reveal a contradiction;
- make a mechanism tangible;
- reset attention;
- land the conclusion.

Do not include a visual if the surrounding prose already performs the same job.
Write alt text that explains the relationship, not merely the objects.

## Production Brief Template

Use this compact template when the user needs a handoff rather than a rendered
artifact:

```text
Central idea:
Audience and moment:
Format and dimensions:
Semantic spine:
Visual metaphor:
Composition:
Object vocabulary:
Palette and contrast:
Typography behavior:
Exact on-canvas copy:
Caption or narration:
Sequence or motion beats:
Accessibility notes:
Originality check:
```

Keep directions spatial and testable. Replace vague terms such as "dynamic" or
"impactful" with positions, scales, states, transitions, and constraints.

## Output Review

Review the sequence both as individual frames and as a whole:

- Remove any frame that repeats rather than advances.
- Confirm that each transition changes visible meaning.
- Check that the first frame makes sense without prior context.
- Check that the last frame resolves rather than merely stops.
- Confirm that type size and contrast remain consistent at delivery dimensions.
- Verify every quote and factual claim.
- Confirm that no frame reconstructs a recognizable source composition.
